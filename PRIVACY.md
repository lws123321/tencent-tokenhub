## Privacy

[Tencent TokenHub] Privacy Policy  
Last Updated: April 30, 2026

### Scope
This plugin is an integration connector between Dify and Tencent TokenHub model APIs.

### Data Processing Statement
- This plugin does not persist user prompts, model outputs, or API keys in its own local database.
- To complete inference requests, user inputs and required request metadata will be transmitted to Tencent TokenHub APIs.
- API keys are used only for authentication when calling Tencent TokenHub.

### Third-Party Service
This plugin relies on Tencent TokenHub as the model service provider.  
All traffic should be sent over HTTPS.  
Please refer to Tencent Cloud privacy and data processing policies for third-party handling details.

### Data Usage and Sharing
- The plugin itself does not sell user data.
- The plugin itself does not share data with additional third parties beyond the configured model provider request path.
- Data retention and downstream processing are subject to Tencent TokenHub service policies.

### Security Commitment
- Follow secure coding and dependency management practices.
- Minimize credential exposure in logs and runtime outputs.
- Follow Dify platform security and review requirements.

### Policy Updates
Policy updates will be reflected in plugin release notes and repository updates.

### Contact
If you have privacy-related questions, please contact the plugin maintainer.
